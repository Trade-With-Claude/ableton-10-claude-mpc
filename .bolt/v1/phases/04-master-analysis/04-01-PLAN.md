# PLAN — Phase 4: Master Analysis

## Goal
Claude can "hear" the master on demand. An `analyze_master(seconds=15, reference=None)` MCP tool records the Live master from BlackHole 2ch while Dorian plays a section. It runs spectrum-advisor's existing analysis modules on that buffer and returns a compact JSON report:
- LUFS-I/S, true peak, PLR and crest
- 6 broad band zones (sub → air), plus deviation vs a reference when one is set
- stereo/mono compatibility, drum punch and pump
- diagnoses as text in coach mode

The analysis library stays in `../spectrum-advisor`, which gains a headless one-shot API and drops Qt from its core dependencies.

## Acceptance Criteria

### AC-1: spectrum-advisor has a headless one-shot API, and Qt is optional
- **Given**: `../spectrum-advisor` with the new `audio.capture.record()` and `analysis/oneshot.py: analyze_buffer()`
- **When**:
  - `analyze_buffer(frames, sr=48000, ref=None, mode="coach", bpm=172)` runs on synthetic 15 s stereo buffers (pink-ish noise + a 50 Hz sine; mono vs wide; silence).
  - `record()` runs with `sounddevice` mocked.
- **Then**:
  - The result is a plain dict that `json.dumps(..., allow_nan=False)` accepts (no NaN/inf/ndarray).
  - It holds `loudness` {lufs_i, lufs_s, true_peak_db, plr_db, crest_db, lra|null}, `bands` (6 zones: sub 20–60, low 60–250, low-mid 250–500, mid 500–2k, high-mid 2–6k, air 6k–20k, dB relative to the total) plus the full 31-band array, `stereo` {correlation, side_fraction, mono_compat_low, mono_delta_lufs}, `drums` (punch per element), `pump_score`, `translation` and `diagnoses` [{severity, category, code, text}].
  - `reference` deviation per zone appears only when `ref` is given.
  - A silent buffer raises `SilentCaptureError` with an actionable message.
  - `record()` raises the existing `SampleRateMismatchError`/`DeviceNotFoundError` on a 44.1 kHz or missing device and returns (n, 2) float32 at 48 kHz otherwise.
  - `pyside6`/`pyqtgraph` live in `[project.optional-dependencies] ui`. A `dev` group pulls in `spectrum-advisor[ui]` so the app's own workflow is unchanged, and `test_imports.py` skips the Qt import when Qt is absent.
- **Verify**: `cd ../spectrum-advisor && uv run pytest -q` all green (existing + new `tests/test_oneshot.py`, `tests/test_record.py`)

### AC-2: The `analyze_master` MCP tool is wired, and resolves the reference
- **Given**: `claude-mpc` depending on `spectrum-advisor` as an editable path dependency (no `[ui]`)
- **When**: `analyze_master(seconds, reference)` is called with `record` mocked to return a synthetic buffer
- **Then**:
  - Capture + analysis run in `asyncio.to_thread`.
  - `seconds` is clamped to 10..60, and the default is 15.
  - The BPM comes from Live's tempo via `ping`, falling back to 174 if Live is unreachable, so the tool still works without Live connected.
  - The reference is resolved as: argument path → `~/.config/spectrum-advisor/session.json` `last_reference_path` → none. The result says which was used (`reference: {path, source: "arg"|"last_used"|null}`), and a missing reference file is a clear error.
  - Device/sample-rate/silence errors come back as tool errors with the fix in the message.
  - `analyze_master` is added to the `.claude/settings.json` allowlist, because it only reads (it records audio and changes nothing in Live).
  - `uv.lock` doesn't contain pyside6.
- **Verify**: `uv run pytest -q` is all green; `grep -c pyside6 uv.lock` returns 0

### AC-3: Claude reports on a real drop, consistent with dpMeter5
- **Given**: Live at 48 kHz with its output on BlackHole 2ch (per the spectrum-advisor README), and dpMeter5 on the master
- **When**: Dorian plays a drop, and Claude calls `analyze_master(15)` (once without a reference, and once with the last-used or a given DnB reference)
- **Then**:
  - Claude reports LUFS-I/S, TP, PLR, the band balance (incl. sub), stereo, and a diagnosis in plain language.
  - LUFS-I and TP agree with dpMeter5 over the same section within ±1 LU / ±1 dB.
  - Live doesn't stutter.
  - Stopping playback and calling again gives the silent-capture error, not a nonsense report.
- **Verify**: manual UAT, recorded in `docs/UAT-phase4.md`

## Tasks

### Task 1: spectrum-advisor one-shot API + Qt split
- **Files** (in `../spectrum-advisor`): `src/spectrum_advisor/audio/capture.py`, `src/spectrum_advisor/analysis/oneshot.py`, `pyproject.toml`, `uv.lock`, `tests/test_imports.py`, `tests/test_oneshot.py`, `tests/test_record.py`
- **Action**:
  - `record(seconds, device_name="BlackHole 2ch", sr=48000) -> np.ndarray`:
    - Calls `validate_device_samplerate` (raise on mismatch).
    - Runs `sd.rec(int(seconds*sr), samplerate=sr, channels=2, dtype="float32", device=idx)` + `sd.wait()`.
    - Returns (n, 2). It's a module-level function next to `AudioCapture`, which is left untouched.
  - `oneshot.py`:
    - `analyze_buffer(frames, sr=48000, ref: ReferenceProfile|None=None, mode="coach", bpm=None) -> dict`.
    - Silence check: peak < 1e-4 or LUFS-I = −inf → `SilentCaptureError("No signal on BlackHole 2ch: is Live playing, and is its output set to BlackHole 2ch?")`.
    - Runs `LoudnessAnalyzer.compute` (whole buffer; LUFS-S = last 3 s), `compute_spectrum`, `stereo.analyze`, `analyze_transients` and `compute_pump_score(bpm=bpm)` on the full buffer, plus `compute_preview`.
    - When `ref` is given, it adds the reference deviation (`lufs_matched_deviation` + `classify_zones`).
    - Builds a `LiveAnalysisResult` and calls `generate_diagnoses` + `diagnoses_to_text(mode)`.
    - Zone summary: power-sum the 31 bands into the 6 zones, expressed relative to total energy (dB).
    - `_jsonable()` turns NaN/±inf into null and ndarrays into rounded lists (1 decimal).
    - Also adds `load_reference_profile(path) -> ReferenceProfile` (reference.load + profile_cached).
  - `pyproject.toml`: move `pyside6`/`pyqtgraph` to `[project.optional-dependencies] ui`, and add `"spectrum-advisor[ui]"` to the `dev` group. `uv lock`.
  - `test_imports.py`: use `pytest.importorskip` for the Qt imports.
  - Tests: synthetic buffers (sine + noise at known levels):
    - JSON-safe output (`allow_nan=False`) and the zone keys
    - a 50 Hz-heavy buffer → the sub zone is the largest
    - mono vs decorrelated → correlation ≈ 1 vs < 0.5
    - silence → error
    - with `ref` → a deviation per zone
    - `record` with mocked `sd.rec`/`query_devices` (48k OK, 44.1k raises)
  - Commit in the spectrum-advisor repo.
- **Verify**: `cd ../spectrum-advisor && uv run pytest -q` is green, and `uv run spectrum-advisor --help` or the app import still resolves Qt via the dev group
- **Done**: false

## Research Done
- spectrum-advisor modules are pure numpy/scipy:
  - `LoudnessAnalyzer` (pyloudnorm, 4× oversampled TP, LRA needs ≥30 s)
  - `compute_spectrum` → 31 third-octave bands
  - `stereo.analyze`, `analyze_transients`, `compute_pump_score(bpm=)`, `compute_preview`
  - `generate_diagnoses(LiveAnalysisResult, ref)` + `diagnoses_to_text(mode)`

  Only `main.py` and `ui/panels`/`dashboard` import Qt (`ui/__init__.py` is a docstring).
- `LiveAnalyzer` throttles transients/pump (None until the 20th tick), so the one-shot API calls them directly and builds `LiveAnalysisResult` itself rather than using `LiveAnalyzer.compute`.
- `validate_device_samplerate` already gives the strict 48 kHz check and a "BlackHole missing" message, so R3 reuses it.
- References: `audio.reference.load()` (resample → 48k) + `profile_cached()` (sha256 → `~/.cache/spectrum-advisor/*.npz`). `ui/session.py` stores `last_reference_path`.
- The master has dpMeter5 (Phase 2/3 sessions), which gives an independent LUFS/TP cross-check for the UAT.
